# Gud's Notebook

欢迎来到我的个人知识库。

这里主要用于整理和沉淀我的学习过程。

> Learn, build, understand, document.

---

## 📐 数学建模

系统整理数学建模中的方法、模型、代码实现以及比赛实践。

主要内容包括：

- 数据预处理
- 数据可视化
- 评价模型
- 预测模型
- 优化模型
- 图论
- 机器学习
- 比赛复盘

我的目标不是单纯记录“某个模型怎么用”，而是进一步回答：

- 这个模型解决什么问题？
- 为什么要使用它？
- 它有哪些假设？
- 有哪些优缺点？
- 什么情况下不应该使用？
- 如何验证结果是否可信？

1. 研究的问题是什么？
2. 为什么这个问题重要？
3. 作者使用了什么方法？
4. 为什么使用这个方法？
5. 核心数学思想是什么？
6. 实验结果说明了什么？
7. 有哪些优点和缺点？
8. 哪些内容值得复现？

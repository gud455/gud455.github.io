MY LEARNING RECORD / 03

这一讲，我学过什么？

上一讲明确了如何打分与计算损失，这一讲进一步讨论：在拟合数据之外，希望模型偏向怎样的解；又该如何根据梯度，一步步更新参数。我学习了正则化、数值与解析梯度、SGD、Momentum、RMSProp、Adam / AdamW，以及学习率调度的基本思路。

01 表达模型偏好数据损失 + 正则项02 沿梯度更新方向 / 步长 / 梯度检查03 理解训练轨迹动量 / 自适应 / 调度

留给自己的三个提醒

  1. 训练损失低，不等于泛化更好。正则化表达对参数或解的偏好，强度仍需用验证集选择；过强也可能使模型欠拟合。
  2. 负梯度是局部方向，不保证任意步长都下降。学习率过大可能震荡或发散；梯度接近零，也不能据此确认已经到达理想的极小值。
  3. 优化器名称不能代替实验设置。学习率、调度、梯度噪声与权重衰减的实现方式，都会影响实际更新。

实验 01 / 拟合得更紧，就一定更好吗？

调整多项式次数与 L2 正则化强度。观察拟合曲线、训练误差和验证误差：更复杂的曲线可以贴近训练点，但也可能把噪声一起拟合进去。

展开 / L1 与 L2 表达的偏好有什么不同？

对输入 x = [1, 1]，w = [1, 0] 与 w = [0.5, 0.5] 都得到分数 1。两者 L1 惩罚均为 1，L2 平方惩罚分别为 1 与 0.5，后者因此更受 L2 偏好。

L1 在许多优化问题中会促使稀疏解，但这个例子里，非负且权重和为 1 的分配具有相同 L1 惩罚；不能说 L1 在此一定唯一选择 [1, 0]。

实验 02 / 同一座“山谷”，怎样走到最低处？

在一个已知的二维凸二次函数上比较更新轨迹。改变学习率、方向曲率与调度，再加入可复现的合成梯度噪声，观察谁在震荡、谁在缓慢前进，以及步长变小后发生了什么。

我想带回训练实践的理解

先确认梯度，再换优化器

数值梯度慢，但可以检查解析梯度或自动微分的实现。检查时需要固定输入和随机性，留意非光滑点及差分步长。

区分 Adam 的 L2 与 AdamW

把 L2 项加入梯度，会影响 Adam 的一阶、二阶矩估计；AdamW 将权重衰减与这条自适应梯度路径解耦。它们通常不等价。

评价模型时也记录优化过程

在我做融合与先验实验时，训练预算、学习率和调度都需要明确。一次训练中的中间优势，还需要在一致预算和最终评价下检查。

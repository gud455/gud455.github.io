这一讲，我学过什么？

从 RNN 编码器—解码器的固定状态瓶颈出发，学习了注意力如何按 query 从多个 value 中汇集信息，再把 Q/K/V、自注意力、多头、位置编码与掩码连接成 Transformer。最后回到视觉：把图像变成 patch token，同样可以进行全局信息交互。

留给自己的三个提醒

  1. 权重由 Q 和 K 决定，输出还取决于 V。同一套注意力权重可以汇集不同内容；自注意力的 Q/K/V 来自同组输入，交叉注意力的 query 与 key/value 则来自不同输入组。
  2. 打乱输入时，纯自注意力的输出也跟着打乱。这里说的是无位置信息、无顺序相关掩码时的置换等变性，并非输出完全不变。位置编码和因果掩码分别提供位置与可见范围的信息。
  3. 全局交互有计算成本。标准稠密注意力包含 N×N 的两两匹配；FlashAttention 可避免显式存下完整注意力矩阵，但不能据此把标准稠密注意力的计算量说成随 N 线性增长。

从注意力到 Transformer，再到 ViT

多头与 block：交互之后，还要变换特征

多个头各自投影 Q/K/V，在不同子空间里进行注意力计算，再拼接并做输出投影。一个 block 还包括逐 token 的 MLP、残差连接与归一化；MLP 在各位置共享参数，跨 token 的混合由注意力承担。

ViT：把二维图像组织成 token

按本讲示例，224×224 图像切成 16×16 的 patch，得到 14×14 = 196 个 token；每个 RGB patch 展平成 768 维，再线性映射到 D 维并加入位置信息。图像分类示例允许 patch 间双向交互，最后对输出平均池化并分类。

结构改动：先认清它改了哪一部分

本讲还接触了 Pre-Norm、RMSNorm、SwiGLU 和 MoE：分别涉及归一化位置、归一化方式、MLP 门控和专家路由。这里只记录它们在 block 中的位置，后续再通过实现与实验加深理解。

与我后续的多模态学习有什么联系？

这一讲让我把“融合”进一步拆成两个问题：谁向谁检索信息，以及被汇集的内容是什么。交叉注意力为不同模态之间的交互提供了一种组织方式，但是否有效仍需对齐方式、复杂度与消融实验支持。注意力热图能展示权重分配，单靠它还不能证明模型的因果解释。

展开 / 位置编码和因果掩码可以互相替代吗？

位置编码把位置信息放进表示；因果掩码约束某个 query 能读取哪些 key。关闭位置编码后，因果掩码本身仍引入了顺序相关的可见范围，所以本页只在两者都关闭时展示纯自注意力的置换等变关系。

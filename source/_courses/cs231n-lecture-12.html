MY LEARNING RECORD / 12

这一讲，我学过什么？

把“监督从哪里来”作为起点，学习了旋转预测、图像补全、着色等前置任务，再走向 MAE、SimCLR、MoCo、CPC 与 DINO。重点是区分预训练目标与真正关心的下游任务：任务设计可以来自数据本身，但表征是否有用仍需要评价。

01 数据本身可以提供目标前置任务 / 视图增强 / 遮挡02 拉近相似，也要保留区分正负样本 / InfoNCE / 坍塌03 学会任务，不等于表征优秀线性探测 / 微调 / 迁移

留给自己的三个提醒

  1. 自监督不等于没有训练目标。标签或目标由变换、视图关系和被遮挡内容构造，仍可以用分类、回归等损失训练。
  2. 增强策略决定哪些变化应被忽略。把两种视图设为正对，是在指定希望保留的一致性。过强裁剪可能丢掉共同语义，不同样本也可能属于同类，负样本构造需要结合任务理解。
  3. 预训练损失和下游能力要分开看。线性探测冻结编码器，只训练线性层；完整微调会更新编码器。重建更好或对比损失更低，都不能单独证明迁移表现更好。

实验 01 / 正样本能从候选里被找出来吗？

固定一个 anchor，调整二维单位向量的夹角、负样本数和温度。观察正样本分到的概率与单 anchor 的 InfoNCE 损失；再试试所有向量完全相同的“坍塌”状态。

实验 02 / MAE 看见什么，又在哪些位置算损失？

把合成图划成 16 个 patch，改变遮挡比例与位置。手动指定预测值，比较只在遮挡位置计算的误差与全图误差；单独改变可见位置的预测，检验两种损失的区别。

本讲方法各自强调什么？

方法我保留的理解
变换预测 / 重建通过旋转、位置、拼图、着色、补全等自动生成目标；设计任务时要留意不需要语义理解的捷径。
MAE编码器只处理可见 patch，较轻的解码器补入 mask token 和位置信息做重建；本讲损失只计算遮挡区域。
SimCLR / MoCoSimCLR 用增强视图、投影头和批内候选做对比；MoCo 用队列和动量更新的 key 编码器，将候选集合大小与当前小批量解耦。
CPC / DINOCPC 对比正确与错误的未来/上下文关系；DINO 用教师—学生的跨视图自蒸馏学习表征，不能简单等同于显式正负样本的 InfoNCE。

与我的多模态学习有什么联系？

这一讲让我开始把“哪些信息应该一致、哪些差异应该保留”放到目标设计中考虑。后续研究图像融合或退化鲁棒表征时，可以借鉴视图一致性与遮挡目标，但不能直接把不同模态的所有差异都当作应消除的噪声；仍需确认任务信息、空间对齐与下游效果。

展开 / 把所有样本映射成同一个向量，不也很“一致”吗？

它满足了一种平凡的一致性，却失去了区分信息。下面的 InfoNCE 示例中，正负候选完全相同时概率均匀，无法识别正样本。不同自监督方法用不同机制处理这类问题；不能把一条方法的防坍塌机制套到所有方法上。

这个代用模型怎样精确求解？

数据标准差固定为 0.6，噪声为标准高斯。对均值为 m 的数据分支，线性混合的均值为 (1−t)m，方差 S(t) = (1−t)²·0.36+t²。平方误差下的最优速度为 v_m(y,t) = −m + [t−(1−t)·0.36]/S(t) · [y−(1−t)m]。

将两组同方差高斯场分别作为无条件/条件预测的代用，均值取 0 与 μ。只核对线性组合，不宣称它们来自同一个联合条件模型。v_cfg = (1+w)v_c − wv_u，对应有效均值 m = (1+w)μ；解析轨迹为 y(t) = (1−t)m + √S(t)z₀。

从 t = 1 到 0 做 N 次反向 Euler 更新，每次 Δt = −1/N。参考末点为 m+0.6z₀。速度场无训练误差，因此显示的差是离散求解误差；不据此预测真实生成质量、多样性或最佳步数。

z₀ 只是一个固定高斯坐标，未随机采样或生成图像。CFG 在真实模型中通常需要条件和无条件两路预测，本实验不测模型延迟。这里的速度、其他扩散参数化中的 v、以及噪声 ε，必须结合各自定义区分。

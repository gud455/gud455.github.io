训练目标与归一化规则

模型 ŷ = wx，单样本损失 ℓ = (wx − y)²/2，导数为 x(wx − y)。固定数据 x = (−2, −1, 0, 1, 2, 3, 4, 5)，y = (−3, −1, 0, 1, 2, 4, 5, 7)。目标是全部 8 个样本的平均损失。

等量时按 (4, 4) 或 (2, 2, 2, 2) 顺次划分；不等量时按 (2, 6) 或 (1, 1, 2, 4) 划分。全局梯度 g = Σ(nᵣ/8)gᵣ。直接平均各卡局部均值，通常只在样本数等大或特殊数值巧合时等于这个目标。

这是无批间耦合的小模型，不含 BatchNorm 或随机算子。真实框架不会仅凭局部均值自动推断所有有效样本或 token 数；需要核对损失 reduction、梯度累积与归约语义。控件只预览一次更新，不执行训练。

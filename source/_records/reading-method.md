## 我希望留下什么

我不希望论文阅读结束后只剩下一段摘要。对我来说，更有用的记录应该说明方法要解决什么、关键模块怎样工作，以及如果自己复现，需要准备哪些条件。

## 我使用的阅读问题

1. 输入、输出与任务目标分别是什么？
2. 方法为什么需要这个模块，它替代或补充了什么？
3. 核心公式里的每个变量与模型中的哪一部分对应？
4. 训练目标和测试流程有没有区别？
5. 数据、设备、参数与评价指标是否清楚？
6. 结果支持了什么结论，哪些问题仍然没有回答？

## 我的复现记录框架

| 部分 | 希望记录的内容 |
| --- | --- |
| 环境 | Python、框架、设备与依赖 |
| 数据 | 来源、手动准备方法与划分 |
| 配置 | 输入尺寸、训练参数与随机种子 |
| 过程 | 日志、checkpoint 与遇到的问题 |
| 结果 | 实际输出、评价设置与限制 |
| 理解 | 哪些内容已经弄清，哪些仍需核对 |

## 对我的研究有什么帮助

当我比较扩散先验或图像融合方法时，这种记录方式能帮助我区分论文原始结论、自己的理解和实验尚未验证的设计选择。

我会继续根据实际阅读与复现经历调整这份框架。

## 先确定，一张表到底测了什么

SDADP v0.2 里同时出现 latent RMSE、可靠度相关性与融合 total。它们回答不同的问题：表征恢复是否准确、退化描述是否准确、融合输出是否符合当前源图像约束。

我现在会先写清每个指标的对象、参照与聚合方式，再把数值放进图表。

| 层次 | 本轮使用的量 | 不能直接替代的结论 |
| --- | --- | --- |
| 先验恢复 | 标准化 latent 全局 RMSE | 融合视觉质量 |
| 可靠度拟合 | R RMSE、skill、相关系数 | 注入后的有效收益 |
| 融合约束 | content、gradient、total | PSNR 或下游检测性能 |
| 计算成本 | 本轮记录了参数量与 NFE | 未实测的延迟、FLOPs、峰值显存 |

## 原始输入、源图像与退化输入

LLVIP 源图像不是额外恢复任务的干净 GT。我的本轮协议在源图像上追加显示图像域的局部暗化与噪声，再用追加退化前的源图像提供训练监督和诊断参照。

验证使用中心 256×256，不应写作原分辨率整图评价。文件名前缀用于分组，也没有证据把它等同于独立物理场景。

## 独立基线与开关消融，分别能说明什么

{% include research-diagram.html kind="controls" %}

独立无先验模型回答“相同训练预算下，增加先验是否值得”；prior_on / prior_off 回答“这个已经训练的先验模型是否使用注入”。两种比较都需要，解释范围也应分别保留。

## 逐图差值比两个总体均值更可追溯

我保留每对图像的方法分数，再计算配对差值。这样可以检查平均收益由哪些样本驱动，以及某类输入是否付出了更大代价。

以最终合成退化为例，prior_on−独立基线的配对均值为 +0.000039，prior_on 更低的比例为 35.8%。这个比例表示样本方向，不能当作收益幅度，也不是独立样本显著性检验。

分组评价同时保留 n。若需要从分组恢复总体均值，应使用有效样本权重；全局 RMSE 还需要先合并平方误差和有效元素，再开方，不能直接平均每批 RMSE。

## 每次运行应留下的最小记录

| 记录 | 本轮保留或需要保留的内容 |
| --- | --- |
| 协议 | 数据清单、裁剪、合成退化、随机种子、精度 |
| 训练来源 | 初始化检查点、优化器、学习率、总步数 |
| 冻结范围 | 参与更新的参数、冻结状态前后比较 |
| 评价 | 总体、逐图、实际变化分组、原始与合成条件 |
| 成本 | 参数与 NFE；待补充实测延迟与显存 |
| 证据状态 | 已执行、只准备脚本、未返回结果分别标注 |

## 暂停一条路线时也要留下完整记录

负结果有助于下一次设计：保留强基线、已有权重、失败条件和未回答问题，能避免换一个名称后重新走一遍相同路径。

本轮暂停任务监督对照，不等于已经验证它无效；尚未执行的实验继续放在计划中。下一轮首先写清研究假设，以及哪一个对照能够支持或推翻它。

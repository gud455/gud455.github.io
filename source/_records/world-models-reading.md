## 为什么开始了解这一方向

在图像融合与扩散模型之外，我最近开始了解世界模型、具身智能、空间智能、VLA、JEPA 和 Agentic AI。当前主要建立概念之间的关系，并准备阅读综述，尚未完成该方向的模型复现。

阅读入口是 [A Comprehensive Survey on World Models for Embodied AI](https://arxiv.org/abs/2510.16732)及其[作者维护的资料仓库](https://github.com/Li-Zn-H/AwesomeWorldModels)。

## 从一个动作条件预测问题开始

一个简化的世界模型可以把当前内部状态 z 和动作 a 映射到后续状态分布：

$$
p_\theta(z_{t+1}\mid z_t,a_t).
$$

智能体据此比较不同动作可能带来的后果。实际方法可能使用观测历史、随机潜变量、视觉 token 或空间表示；上式只用来明确“当前信息、动作、未来”三者的关系。

与静态图像问题相比，我在阅读时会额外追问动作如何进入模型，预测误差如何在多步滚动中积累，以及预测怎样支持决策。

## 先区分邻近概念

| 概念 | 本阶段先关注的问题 |
| --- | --- |
| 世界模型 | 环境如何演化，预测能否支持规划或控制？ |
| 具身智能 | 智能体怎样通过感知、动作与环境交互？ |
| VLA | 视觉、语言条件怎样连接到动作输出？ |
| JEPA | 怎样在表征空间预测目标，避免必须重建所有像素？ |
| 空间智能 | 怎样表示几何、位置、关系与可交互结构？ |
| Agent | 怎样组织目标、工具、记忆与行动反馈？ |

这些概念可以组合，具体方法仍要看输入、输出、训练目标和是否具有环境动力学建模。

## 用综述提供的三个轴组织阅读

综述按功能、时间建模和空间表示组织世界模型。我准备沿三个问题读：模型是否与决策直接耦合，怎样表示时间上的变化，以及采用向量、token、空间网格还是分解的渲染表示。[综述原文](https://arxiv.org/abs/2510.16732)

这比直接按模型名称收集论文更方便比较：同样使用视频生成，方法可能分别服务于视觉预测、数据构造或行动规划。

## 阅读中需要分别核对的评价

| 评价层次 | 要寻找的证据 |
| --- | --- |
| 视觉预测 | 未来帧或特征的误差、清晰度和多样性 |
| 一致性 | 对象、几何、接触关系与长时演化是否合理 |
| 控制与规划 | 预测是否真正改善任务成功率或回报 |
| 运行代价 | 多步生成成本、延迟与控制频率是否匹配 |

画面逼真和决策有效需要分别验证。这也延续了我在融合实验中形成的习惯：中间表示的质量，要通过最终任务的评价进一步检验。

## 下一步如何进入具体项目

先整理综述的任务定义和分类，再选一条能够获得代码、数据和评价环境的路线精读。后续小实验需要有明确任务、基线与评价预算，再考虑模块修改。

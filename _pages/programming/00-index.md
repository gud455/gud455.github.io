## 我的学习原则

> 把整个教程重新复制一遍。

主要记录三种东西：

### 1. 经常忘的

例如某个 API。

### 2. 容易出错的

例如：

- Python 可变对象
- NumPy shape
- C++ iterator

### 3. 实际解决过的问题

例如：

> 一个 Bug 为什么出现，以及最后如何解决。
